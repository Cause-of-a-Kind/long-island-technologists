01 .brand_essence

Who we are

A collective of curious and passionate technologists bound together by a love for technology and a mission to strengthen the local tech community. Monthly meetups at Flux Coffee in Farmingdale, talks from industry leaders, and real connection.

Brand personality

  • Welcoming. Seasoned pro or first day in tech, there's a seat for you.
  • Technical, never stuffy. Code nods like .what_we_do, delivered with a smile.
  • Local and proud. Long Island first, always.
  • Bright and clean. Light canvas, one electric accent.

A heavy LONG beside a light ISLAND, with a widely tracked TECHNOLOGISTS beneath, all set over a soft gray silhouette of Long Island itself. The weight contrast is the signature. Never rebuild it in live type.

Do

Don't

  • Stretch, rotate, outline, or drop the island silhouette.

Radius

sm 4px
md 6px
lg 8px
xl 12px

Buttons and badges: md. Icon tiles: lg. Cards and rows: xl. Round icon wells: 50%.

Signature effects

Blueprint grid

1px lines at 10% neon, 50px cells, 20% opacity, over a 135deg 5% wash. Hero only.

Glow divider

2px line fading from transparent to neon and back, 10px glow. Separates big ideas.

Connects

Neon text glow

0 0 10px at 40%. One highlighted phrase per screen.

Iconography

Feather / Lucide style line icons: 24px grid, 2px stroke, round caps and joins, stroke="currentColor", no fills. Tint them neon blue inside a 10% tile or circle. Sizes: 16px inline, 20px meta, 24px cards, 32px feature wells.

Motion

Everything eases at all 0.3s ease. Cards lift 5px, rows slide 4px, buttons fade to 70%. Calm and quick, never bouncy (the hero scroll cue is the lone exception).

LIT Brand Style Guide07
07 .voice_and_copy

Sound like a neighbor who codes

Warm, inclusive, and energized. We talk to people, not at them. Short sentences, active verbs, and a wink of developer humor.

Community first

"We" and "you," never "the organization." Every message is an invitation.

Local pride

Name the place. Long Island, Farmingdale, Flux Coffee. Roots make it real.

Playfully technical

Snake case labels like .past_presentations nod to the craft without gatekeeping.

Say it like this

  • Where Long Island's Tech Community Connects
  • Want to be a techie too?
  • Building Long Island's Tech Scene
  • Join Next Meetup
  • Educate, stimulate and cultivate with the LIT community.

Not like this

  • Leverage synergistic networking paradigms.
  • Exclusive event for senior engineers only.
  • CLICK HERE NOW!!!
  • Walls of jargon with no human in them.

Copy conventions

Name"Long Island Technologists" on first mention, "LIT" after. Always caps: LIT, never Lit.
HeadlinesTitle Case, 3 to 7 words, no ending period. Questions are welcome.
ButtonsVerb first, 2 to 4 words: Join Next Meetup, RSVP on Eventbrite, Get In Touch.
Section labelsDot prefix plus snake case, lowercase: .what_we_do, .sponsor_lit.
Dates and times"Thursday Evening," "7:00 PM EST." Mono for compact dates.
ContactLIT@causeofakind.com
EmojiNot in site UI. Icons do that job.

08 .token_reference

Tokens for builders and AI skills

Paste this block into any prompt, skill, email template, or stylesheet to stay on brand. Source of truth: _sass/base/_variables.scss.

/* Long Island Technologists (LIT) brand tokens v1.0 */
:root {
  /* Accent */
  --neon-blue: #0ea5e9;          /* CTAs, links, labels, highlights */
  --neon-glow: rgba(14,165,233,.4);  /* text-shadow / box-shadow glow */
  --neon-blue-tint-2:  rgba(14,165,233,.02);
  --neon-blue-tint-5:  rgba(14,165,233,.05);
  --neon-blue-tint-10: rgba(14,165,233,.10);
  --neon-blue-tint-20: rgba(14,165,233,.20);
  /* Neutrals */
  --light-bg: #fafafa;  --card-bg: #f5f5f5;  --border-color: #e0e0e0;
  --text-dark: #141414; --text-gray: #737373; --text-white: #ffffff;
  /* Shape and depth */
  --radius-sm: 4px; --radius-md: 6px; --radius-lg: 8px; --radius-xl: 12px;
  --shadow-10: rgba(0,0,0,.1); --shadow-5: rgba(0,0,0,.05);
  /* Type */
  --font-sans: "Inter", -apple-system, "Segoe UI", Roboto, sans-serif;
  --font-mono: "Geist Mono", "Courier New", monospace;
}
/* Google Fonts: Inter 400;500;600;700 + Geist Mono 100..900 */
/* Scale: h1 56/700/1.2  h2 40/700  h3 24/600  body 16/400/1.8  label 14 mono caps +.1em */
/* Motion: all .3s ease   Layout: max 1280px, section 48px/32px, gap 32px, bp 768px */

Quick checklist

  • Light background, dark headlines, gray body.
  • Neon blue only where you want the eye to go.
  • One glowing highlight phrase per screen.
  • Mono, snake case section label above each H2.
  • Cards: #F5F5F5, 1px border, 12px radius.
  • Line icons, 2px stroke, in 10% blue tiles.
  • Logo on light surfaces, never recolored.
  • Copy that sounds like an invitation.
